That means this result answers "can THIS Claude Code cloud session reach
official.nba.com" (no) but does NOT by itself answer "would a GitHub Actions
runner be blocked too" -- GH Actions runners are a different network
environment with their own (typically much more open) egress, not subject to
this session's proxy policy. Settling the GH-Actions question needs a real
test from an actual GH Actions runner in September, or a design decision to
default to the local-scheduled-task path if that test isn't run before then.
